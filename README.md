# Employee Salary Analysis

## Project Goal
Answer business questions about employee salaries using Python data analysis.

## Key Questions Answered
1. **Highest paid employee per department** (using idxmax)
2. **Average salary by department** (groupby + bar chart)
3. **Correlation between experience and salary** (correlation coefficient + scatter plot)
4. **Salary outliers by department** (boxplot)
5. **Overall salary distribution** (histogram)

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## Dataset
Employee data including: Name, Department, Monthly Salary, Experience Years.

## Sample Insight
- No strong linear correlation between experience and salary (correlation = 0.074).
- Some departments have clear salary outliers.
